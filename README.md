# Shanmugapriya-Jayaraman-Mars
Portfolio project for Intro to Programming course with Code the Dream
Shanmugapriya Jayaraman

How to Run the Project:

Clone the repository to your computer:

git clone https://github.com/jspriya/Shanmugapriya-Jayaraman-Mars.git

Open the project folder in your code editor (for example, VS Code).

Alternatively, in the VS Code, Click on menu Run -> Run Without Debugging.

Open the index.html file in your web browser.
